React + Vite
Этот шаблон предоставляет минимальную настройку для работы React с Vite, включая HMR (Hot Module Replacement — «горячую» замену модулей).

В настоящее время доступны два официальных плагина:

@vitejs/plugin-react использует Oxc

@vitejs/plugin-react-swc использует SWC

React Compiler (Компилятор React)
Компилятор React не включён в этот шаблон из-за его влияния на производительность разработки. Чтобы добавить его, см. эту документацию (https://react.dev/learn/react-compiler/installation).
