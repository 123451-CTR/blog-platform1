React + Vite Этот шаблон предоставляет минимальную настройку для работы React с Vite, включая HMR (Hot Module Replacement — «горячую» замену модулей) и некоторые правила ESLint.

В настоящее время доступны два официальных плагина:

@vitejs/plugin-react использует Oxc

@vitejs/plugin-react-swc использует SWC

Компилятор React (React Compiler) Компилятор React не включен в этот шаблон из-за его влияния на производительность разработки. Чтобы добавить его, ознакомьтесь с этой документацией (https://react.dev/learn/react-compiler/installation).
